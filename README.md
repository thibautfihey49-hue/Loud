# 🔊 Loud — Amplificateur Audio Vocal

Application Android d'amplification audio avec isolation vocale puissante et réduction de bruit.

## ✅ Caractéristiques
- Amplification réglable ×1 à ×30
- Filtre passe-bande vocal : 300 Hz – 3400 Hz
- Réduction de bruit adaptative
- Filtre à encoche 50 Hz
- Faible latence (~20ms)
- Build automatique de l'APK via GitHub Actions

## ⚠️ Usage
- **Casque OBLIGATOIRE** pour éviter le larsen
- Usage légal uniquement

## 📲 Télécharger l'APK
Allez dans **Actions** → dernier workflow → **Artifacts** → **Loud-APK-Debug**
